# Code of Conduct

## Notre engagement

NVO987 – Culture Visuelle Moderne et Contemporaine s'engage à maintenir un
environnement respectueux, professionnel et constructif pour toutes les
personnes qui contribuent au projet.

## Comportements attendus

Les contributeurs sont invités à :

- communiquer avec respect et courtoisie ;
- privilégier les échanges constructifs ;
- respecter les différences d'opinions et de perspectives ;
- fournir des informations exactes et vérifiables lorsque cela est possible ;
- signaler les erreurs de manière constructive ;
- respecter les licences et les sources des données.

## Comportements inacceptables

Ne sont pas acceptés :

- le harcèlement ;
- les propos discriminatoires ou haineux ;
- les menaces ;
- les attaques personnelles ;
- la publication de données personnelles sans autorisation ;
- toute tentative de compromettre la sécurité du projet.

## Signalement

Les problèmes liés au comportement peuvent être signalés à :

contact@nvo987.eu

Les problèmes de sécurité doivent être signalés conformément à
`SECURITY.md`.

## Application

Les responsables du projet peuvent supprimer, modifier ou refuser des
contributions qui ne respectent pas ce code de conduite.

## Portée

Ce code de conduite s'applique aux espaces de contribution liés au projet
NVO987.eu – Sites UNESCO en France.
