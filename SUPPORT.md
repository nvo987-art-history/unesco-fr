# Support

## General questions

For questions concerning NVO987.eu – Sites UNESCO en France:

contact@nvo987.eu

## Data questions

The website uses data derived from Wikidata.

For questions concerning a specific Wikidata item or factual correction,
please provide the relevant place name and, when possible, the Wikidata
reference.

## Website problems

Please include:

- the URL concerned;
- the browser and device;
- a description of the problem;
- the steps required to reproduce it.

## Security

Do not report security vulnerabilities through public issues.

Please follow the procedure described in `SECURITY.md`.
