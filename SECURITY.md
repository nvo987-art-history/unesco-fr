# Security Policy

## Supported version

The current published version of NVO987.eu – Sites UNESCO en France is
actively maintained.

## Reporting a security issue

If you discover a security vulnerability affecting the website or its
repository, please report it privately.

Email:

contact@nvo987.eu

Please do not publicly disclose a vulnerability before the issue has been
reviewed.

## What to include

Please provide, when possible:

- a description of the issue;
- the affected file or URL;
- reproduction steps;
- the potential impact;
- screenshots or technical details when useful.

Do not include passwords, private keys, authentication tokens or other
sensitive information in a public issue.

## Privacy

This project is designed without user accounts, advertising tracking,
profiling or unnecessary collection of personal data.
