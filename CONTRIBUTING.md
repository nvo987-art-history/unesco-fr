# Contributing

Merci de votre intérêt pour NVO987.eu – Sites UNESCO en France.

## Projet

NVO987.eu est une publication culturelle et documentaire en ligne éditée par :

**NVO987 – Culture Visuelle Moderne et Contemporaine**

Le projet documente les sites du patrimoine mondial de l'UNESCO situés en France.

## Données

Les données présentées sur le site proviennent de Wikidata.

Licence des données :

**CC0 1.0 Universal**

Les corrections ou améliorations concernant les données doivent, lorsque cela
est possible, être vérifiées à partir de sources publiques fiables.

## Contributions au code

Avant de proposer une modification :

1. Vérifiez que la modification correspond à l'objectif du projet.
2. Évitez d'ajouter des services de tracking ou d'analyse.
3. N'ajoutez pas de collecte de données personnelles sans nécessité clairement documentée.
4. Préservez le fonctionnement du site statique.
5. Vérifiez le HTML, le CSS, le JavaScript et les fichiers JSON avant de soumettre une modification.

## Pull requests

Une pull request devrait :

- avoir un objectif clairement décrit ;
- contenir uniquement les changements nécessaires ;
- expliquer les éventuelles modifications importantes ;
- ne pas inclure de secrets, clés API ou informations personnelles ;
- conserver la compatibilité avec GitHub Pages.

## Données Wikidata

Les modifications du contenu provenant de Wikidata doivent être effectuées
avec prudence. Les problèmes liés aux données peuvent également être signalés
à la source lorsque cela est approprié.
